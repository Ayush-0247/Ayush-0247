### 🛡️ Plutus Chat — *Ephemeral Secure Communication Line*
> *Owner-controlled ephemeral real-time communication line with zero persistent database storage.*

**Tech Stack:** `React 19` `Node.js 24` `Socket.IO` `Express` `Tailwind CSS v4` `Framer Motion` `BcryptJS` `QRCode` `TypeScript`

- 🔒 **Zero Persistent DB Storage:** Built for temporary, owner-controlled communication sessions with server-authoritative lifecycle destruction.
- 🔑 **Cryptographic Security:** Secured using cryptographic passkeys and hashed authentication (`bcryptjs`).
- ⚡ **Low-Latency Messaging:** Powered by WebSocket duplex channels (`Socket.IO 4.8`) for instant message delivery and session events.
- 📱 **QR Code Access:** Integrated QR code generation (`qrcode`) for instant secure connection pairing and mobile session joining.
- 🎨 **Modern & Fluid UI:** Interactive, smooth interface crafted with **React 19**, **Motion** animations, **Tailwind CSS v4**, and **Lucide Icons**.
